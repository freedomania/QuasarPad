# Support QuasarPad

QuasarPad is free and open source (MIT). You can use all features without paying.

## Ways to help (no money needed)

1. **Star** the repository on GitHub  
2. **Report bugs** or ideas via [Issues](https://github.com/freedomania/QuasarPad/issues)  
3. **Share** the app with people who need an offline toolkit  
4. **Pull requests** if you can code  

## Optional donations

If you want to support development financially, you can add a donation link here later, for example:

- GitHub Sponsors (when enabled on the account)
- Ko-fi / Buy Me a Coffee
- PayPal

Until a link is published, starring the repo and filing issues is the best support.

## What about “Supporter” status?

**Recommendation for QuasarPad:** do **not** lock core features behind payment.

| Approach | Pros | Cons |
|----------|------|------|
| **Thank-you only** (recommended) | Keeps trust; everyone gets full offline tools | Less “exclusive” feeling |
| Name in README / About | Simple recognition | Manual update |
| Early access builds | Testers feel special | More release work |
| Extra themes / icons pack | Optional cosmetic perk | Must maintain packs |

### Suggested policy

- **All tools stay free** (editor, converters, markdown, etc.).
- Supporters get:
  - Thanks in `SUPPORTERS.md` (optional, with permission)
  - Priority reply on GitHub issues (best-effort)
  - Say in About: “Supported by the community”

Avoid:
- Removing features from the free build
- Online license checks (breaks offline-first)
