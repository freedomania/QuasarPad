# Support QuasarPad

QuasarPad is **free and open source** (MIT). All features are available without payment.

## Ways to help (no money needed)

1. **Star** the repository  
2. **Report bugs** or feedback via [Issues](https://github.com/freedomania/QuasarPad/issues) (labels: `bug`, `feedback`)  
3. **Share** the app with others  
4. **Pull requests** if you can code
