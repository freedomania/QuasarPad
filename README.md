# QuasarPad

A clean, lightweight Notepad alternative for Windows.

**Pure Mode by default • Markdown to HTML • No telemetry • Fully offline**

## Features
- Pure Mode (clean like classic Windows 10 Notepad)
- Open and save any text-based file
- No auto-save / session restore by default
- Markdown → HTML Converter (Live Preview + clean full HTML)
- Dark Mode
- Encoding support
- Portable + Installer versions
- Free + optional donation / Supporter

## Requirements
- Windows 10 / 11 (64-bit)

## Building
```bash
dotnet restore
dotnet build
dotnet publish -c Release
```
